# Customer Analysis (מ.ב.א) — מיגרציה מ-Replit

פרויקט לניתוח הלקוחות של מ.ב.א, שנכתב במקור ב-Replit ומיועד למיגרציה לכאן.

> ממתין לקוד. שלח נתיב מקור / ייצוא Replit (zip או git) ואעתיק לכאן, ואז:
> אזהה את ה-stack (Python / Node / …), אתעד תלויות והרצה, ואתאים למבנה הפרויקט.
>
> חשוב: סודות/מפתחות (Replit Secrets, `.env`) **לא** נכנסים ל-git — נשמור אותם מקומית בלבד.
