# בקשה ל-IT — חשבון שירות לקריאת נספחי הזמנות

הודעה מוכנה לשליחה. הרקע הטכני שמתחתיה נועד לענות על שאלות המשך, לא לשליחה.

## המייל

**נושא: בקשה לחשבון שירות בדומיין — קריאת נספחי הזמנות מהפריוריטי**

היי,

אני צריך חשבון שירות בדומיין עבור שירות Windows חדש שמגיש לכיילים את המסמכים שמצורפים להזמנות בפריוריטי.

**מה אני מבקש:**

| | |
|---|---|
| שם מוצע | `MABA\svc-attachments` |
| הרשאה | **קריאה בלבד** על `\\maba-priority\Priority\Attachments` — כולל תיקיות המשנה |
| סיסמה | **לא פגה** (Password never expires) |

**זה כל מה שצריך.** אין צורך בהרשאות מנהל, אין צורך בכניסה אינטראקטיבית, ואין צורך בגישה לשום שיתוף אחר. ההרשאה "Log on as a service" מוגדרת אוטומטית ע"י סקריפט ההתקנה שלנו — לא צריך לטפל בה.

**למה חשבון ייעודי ולא קיים:** השירות רץ מתחת ל-SCM וקורא קבצים מהשיתוף. חשבון המחשב (LocalSystem) נדחה, וחשבון אישי יפיל את השירות ביום שהסיסמה מתחלפת — בשקט, בלי התראה, כשכייל בשטח פותח הזמנה ולא רואה כלום.

תודה,
אלירן

## רקע טכני — למקרה שישאלו

**מה השירות עושה.** `MabaOrderAttachments`, שירות net10, קורא את הנתיבים מטבלת `dbo.CrmOrderAttachments` ב-`CalibratorProd`, פותח את הקבצים מהשיתוף וממיר אותם ל-PDF לכייל. MBA-930.

**היקף הגישה.** 2,325 קבצים תחת `\\maba-priority\Priority\Attachments\Documents\YYYY\MM\`. קריאה בלבד — השירות לא כותב, לא מוחק ולא משנה דבר בשיתוף. ה-PDF-ים המומרים נשמרים מקומית ב-`C:\ProgramData\Maba\OrderAttachments\pdf-cache`.

**מה כבר נוסה ונכשל, לפי הסדר:**

| ניסיון | תוצאה |
|---|---|
| LocalSystem | נדחה — מציג את עצמו כ-`COMP1$`, אין לו הרשאה על השיתוף |
| חשבון אישי, `sc.exe` | `1639` — הסיסמה בשורת פקודה |
| חשבון אישי, `New-Service` | השירות נוצר, ואז `1069` — חסרה "Log on as a service" |
| חשבון אישי, אחרי הענקת ההרשאה | הסיסמה נדחתה ע"י ה-SCM |

הקוד עצמו מאומת מקצה לקצה מול PROD: הזמנה אמיתית, PDF-ים אמיתיים, 215 מילישניות מהקאש. **החשבון הוא הדבר היחיד שחסר.**

**על איזה שרת.** עדיין לא נסגר. ההיגיון אומר אותו שרת שמריץ את `MabaInstructionAssistant` ואת `QCCAnalytics`. שווה לציין את זה ל-IT כדי שידעו איפה החשבון יידרש.

**אימות אחרי שהחשבון נפתח:**

```powershell
& "<repo>\scripts\Install-OrderAttachments-Service.ps1" `
  -ServiceAccount 'MABA\svc-attachments' -ServiceAccountPassword (Read-Host -AsSecureString)
```

הסקריפט מסיים בבדיקת `/health` ואומר במפורש אם השיתוף נגיש. אם יוצא `attachment share: reachable` — הכל עובד.
