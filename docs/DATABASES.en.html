1. Overview & Architecture

The system has three main databases. The ERP (Priority) is the source of truth; data is synced from it into Calibrator (the calibration system DB, SQL Server on AWS) via stg.Merge* procedures. The APP (Next.js) and the C# server (VCT) work against Calibrator; the link between the APP and the server is a WebSocket (live measurement values) plus the shared database.
Priority (amaba, SQL Server) ── stg.Merge* / SSIS ──▶ Calibrator (AWS SQL Server 2022)
Calibrator ◀── Prisma (sqlserver://) ──▶ APP (Next.js)
9100 / calibration instruments ──GPIB/Serial──▶ VCT server (C#, .NET 4.8) ──WebSocket ws://localhost:5001/ws/──▶ APP UI
QCC Analytics (local PostgreSQL) ◀── Python sync ── Priority (reports/analytics)
