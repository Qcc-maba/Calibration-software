## למה ה-34401A כאן ולא באלקטרוניקה

מבחינת חומרה הוא **מודד ספרתי**, כלומר מכשיר אלקטרוניקה. אבל בתוך המערכת הזו הוא מוגדר
`VDC` עם חיישן `FRTD`: הוא קורא את ההתנגדות של PT100 ארבעה-חוטים, וה-BL ממיר אותה למעלות
לפני השידור. **התפקיד שלו כאן הוא מדידת טמפרטורה**, ולכן זה מקומו.

זו גם הסיבה שהיחידה שהוא משדר היא `Celsius` ולא `Volt` — ראה `HardwareBL_Settings.UnitsForSensor`.

## מלכודת שחוזרת בכל המשפחה: `MeasureTypes.VDC`

**`VDC` בקוד הזה אינו "וולט".** `HydraCalculations.ProcessResults` מעביר אותו דרך
`CalcResistanceToTemperatureITS90` ומפיק `Sample.Units.Celsius` — זו האיות הישן ל"התנגדות
שנקראת כטמפרטורה". מכשיר שבאמת מוציא וולט משתמש ב-`VoltageDC`.

באותו אופן, חיישן `RTD` / `FRTD` / תרמוקופל **גובר על ה-MeasureType** וקובע `Celsius`, כי ה-BL
ממיר לפני השידור.
