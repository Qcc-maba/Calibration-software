1. סקירה וארכיטקטורה

המערכת מורכבת משלושה בסיסי נתונים עיקריים. ה-ERP (Priority) הוא מקור האמת; ממנו מסונכרנים נתונים ל-Calibrator (בסיס הנתונים של מערכת הכיול, SQL Server ב-AWS) דרך פרוצדורות stg.Merge*; ה-APP (Next.js) וה-שרת ה-C# (VCT) עובדים מול Calibrator, כשהחיבור בין ה-APP לשרת הוא WebSocket (ערכי מדידה חיים) ובסיס הנתונים המשותף.
Priority (amaba, SQL Server) ── stg.Merge* / SSIS ──▶ Calibrator (AWS SQL Server 2022)
Calibrator ◀── Prisma (sqlserver://) ──▶ APP (Next.js)
9100 / מכשירי כיול ──GPIB/Serial──▶ שרת VCT (C#, .NET 4.8) ──WebSocket ws://localhost:5001/ws/──▶ APP UI
QCC Analytics (PostgreSQL מקומי) ◀── Python sync ── Priority (דוחות/אנליטיקה)
